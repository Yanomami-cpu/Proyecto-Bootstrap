# Bootstrap y los pueblos originarios de Venezuela

Presentación en reveal.js (~10 min) para FP de Diseño Web, con una demo hecha íntegramente en Bootstrap. Sin instalación: abre los HTML en el navegador.

- `presentacion/index.html` — la presentación. Flechas para avanzar, `S` notas del orador (con tiempos), `F` pantalla completa, `Esc` vista general.
- `demo/index.html` — blog de demo sobre los pueblos Yanomami, Timotocuicas, Pemón, Warao y Wayuu, basado en la plantilla [Blog](https://getbootstrap.com/docs/4.0/examples/blog/) de Bootstrap (adaptada a Bootstrap 5.3). Se muestra en vivo en la diapositiva 9.
- Para publicarla: GitHub → Settings → Pages → rama `main`, carpeta `/ (root)`.
