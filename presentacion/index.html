Bootstrap, pero con sabor originario

Un framework explicado con Yanomami, Pemón, Warao y Timotocuicas

Nota: Tucupita es la capital del estado Delta Amacuro, territorio del pueblo Warao; por eso usamos Warao. Las comparaciones son de inspiración y con respeto.

¿Qué es Bootstrap?

CSS + JS ya hecho

Clases listas para botones, menús, tarjetas y rejillas.

Mobile first

Se diseña primero para el móvil y luego se amplía.

Open source

Nació en Twitter y hoy lo usa medio internet.

Es el conuco del frontend: llegas y ya está sembrado.

Chiste: el conuco es la parcela de cultivo tradicional. Con Bootstrap no empiezas de cero.

Cómo usarlo en 2 pasos

1. Enlaza el CDN

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

2. Pon clases

<button class="btn btn-primary">Entrar</button>

Sin escribir CSS, ya tienes un botón con estilo. Magia, pero con documentación.

Breakpoints: las terrazas timotocuicas

PrefijoDesdePantalla
(sin prefijo)0 pxMóvil
sm576 pxMóvil grande
md768 pxTablet
lg992 pxLaptop
xl1200 pxEscritorio
xxl1400 pxPantalla grande

Cada escalón sube la ladera, y tu diseño se reacomoda: col-md-6 = 6 columnas desde tablet.

Los pueblos andinos timotocuicas cultivaban en terrazas. Cada breakpoint es un nivel nuevo del terreno.

Más valores de Bootstrap

Utilidades

m-3, p-4, d-flex, text-center. Clases pequeñas que sostienen todo, como los tepuyes de los Pemón.

Responsive

Se adapta a cada pantalla, como el agua del delta, hogar de los Warao en Tucupita.

Componentes

Navbar, card, modal y carousel: el conuco ya cultivado.

Y con las variables --bs-primary puedes cambiar la paleta entera.

Bootstrap sostiene tu diseño, no lo reemplaza

Personaliza colores, tipografía y espacios para que no parezca “otro sitio Bootstrap”.

Cierre para diseñadores: usa el framework como estructura y pon tu identidad encima.
